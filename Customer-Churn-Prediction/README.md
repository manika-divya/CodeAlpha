\# Customer Churn Prediction



\## Project Overview

This project predicts whether a customer is likely to leave a bank using Machine Learning classification algorithms.



\## Objective

To build a predictive model that identifies customers at risk of churn.



\## Dataset

\- Dataset: BankChurners.csv

\- Number of Records: 10,127

\- Target Column: Attrition\_Flag



\## Technologies Used

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Scikit-learn

\- Jupyter Notebook



\## Machine Learning Models

\- Logistic Regression

\- Random Forest Classifier



\## Evaluation Metrics

\- Accuracy

\- Recall

\- ROC-AUC Score

\- Confusion Matrix

\- Classification Report



\## Project Workflow

1\. Data Loading

2\. Data Cleaning

3\. Exploratory Data Analysis (EDA)

4\. Data Preprocessing

5\. Model Building

6\. Model Evaluation

7\. Feature Importance

8\. Conclusion



\## Conclusion

Random Forest performed better than Logistic Regression in predicting customer churn.
