\# Sales Forecasting using ARIMA



\## Project Overview



This project predicts future sales using historical sales data and the ARIMA time-series forecasting model.



\## Objectives



\- Analyze historical sales

\- Identify sales trends

\- Forecast future sales

\- Compare actual and predicted sales



\## Dataset



\- Superstore Sales Dataset



\## Technologies Used



\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Statsmodels

\- Scikit-learn

\- Jupyter Notebook



\## Machine Learning Model



\- ARIMA (AutoRegressive Integrated Moving Average)



\## Evaluation Metrics



\- MAE (Mean Absolute Error)

\- RMSE (Root Mean Squared Error)



\## Project Workflow



1\. Data Loading

2\. Data Cleaning

3\. Time Series Preparation

4\. Exploratory Data Analysis

5\. ARIMA Model Training

6\. Sales Forecasting

7\. Model Evaluation

8\. Visualization

9\. Conclusion



\## Results



The ARIMA model successfully forecasted future sales and captured the overall sales trend.
